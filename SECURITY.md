# Security Policy

Coldline handles backup data and credentials, so security reports are taken seriously.

## Reporting a vulnerability
Please **do not open a public issue.** Use GitHub's
[private vulnerability reporting](https://github.com/joeygrasso/coldline-backup-service/security/advisories/new).
Include affected version/commit, impact, and reproduction steps.

You can expect an acknowledgement within 7 days. Fixes are released as soon as
practical and credited to the reporter unless you prefer otherwise.

## Supported versions
Pre-1.0: only the latest `main` is supported.
